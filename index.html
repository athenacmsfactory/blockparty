Veelgestelde vragen

Alles wat je moet weten over het gebruik van de Blockparty-template.

Blockparty is een herbruikbare, statische design-template gebouwd met vanilla HTML, CSS en JavaScript. Het bevat veelgebruikte UI-componenten zoals een split-hero, oneindige marquee, kaartstapel met shuffle, en een accordion — zonder enige runtime-afhankelijkheid.
De template gebruikt uitsluitend HTML5, CSS (met custom properties voor design tokens) en vanilla ES-modules JavaScript. Vite wordt gebruikt als build-tool en dev-server. Het lettertype Bricolage Grotesque (OFL-licentie) wordt zelf gehost als variabel woff2-bestand.
Ja. Alle componenten gebruiken fluid typography (clamp), responsive grid-layouts en media queries voor breakpoints. De header schakelt automatisch over naar een hamburger-menu op kleinere schermen. De kaartstapel is volledig touch-compatible via Pointer Events.
Alle kleuren, font-groottes, spacing en motion-waarden zijn gedefinieerd als CSS custom properties in src/styles/tokens.css. Pas de waarden in :root aan en de hele template volgt automatisch. Geen Sass, geen preprocessor — puur platform.
Push naar de main-branch. De meegeleverde GitHub Actions workflow (.github/workflows/deploy.yml) bouwt automatisch de productie-bundle en publiceert deze naar GitHub Pages. Geen handmatige stappen vereist na de eerste push.

Klaar om te bouwen?

Clone de repo, pas de tokens aan, en lanceer jouw project in minuten. Geen afhankelijkheden, geen lockin — volledig van jou.
